# Taste of Africa 🍲

## About the Project
Taste of Africa is a website that explores African food, recipes, and culinary traditions from different regions of Africa.

The website helps visitors learn about African dishes, discover recipes, and understand the cultures behind them.

## Features
- Explore African dishes from different regions.
- View recipes and cooking instructions.
- Watch cooking tutorial videos.
- Filter recipes by region.
- Save favorite recipes.
- Change between dark and light mode.
- Adjust ingredient quantities based on servings.
- Contact form with input validation.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- Local Storage
- YouTube embeds
- Google Maps

## Project Structure
- `index.html` – Home page
- `about.html` – About the project
- `contact.html` – Contact page
- `region-*.html` – Culinary region pages
- `recipe-*.html` – Individual recipe pages
- `styles.css` – Website styling
- `script.js` – Website functionality
- `images/` – Website images

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
